# What-Makes-a-Song-Popular-
What drives a track's Spotify success? Estimating the impact of audio features is biased by unobserved artist fame and endogenous production choices. To solve this, our analysis shifts from a baseline Pooled OLS to Artist Fixed Effects, using leave-one-out IV (2SLS) and genre-specific Within-2SLS (FE-IV) models with cluster-robust SE.
